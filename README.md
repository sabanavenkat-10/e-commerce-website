# E-Commerce Website

## About the Project
The E-Commerce Website is a frontend web development project designed to provide an online shopping interface. Users can explore products and view them through a simple and attractive website design.

## Features
- Attractive homepage
- Product display section
- Product cards with images
- User-friendly navigation
- Responsive website design

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Type
Frontend Web Development Project

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open the `index.html` file in your browser.
